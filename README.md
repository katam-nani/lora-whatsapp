# LoRa Messenger — Offline WhatsApp

Offline peer-to-peer messenger powered by LoRa radio and STM32 LoRa-E5 mini.

## Features
- WhatsApp-style chat interface
- Image send & receive over LoRa
- Web Serial API for browser-based connection
- STM32 LoRa-E5 mini firmware included
- No internet required — Range up to 10 km

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app:
   ```bash
   npx expo start
   ```

## Firmware
Flash `firmware/messenger.ino` to your STM32 LoRa-E5 mini board.
